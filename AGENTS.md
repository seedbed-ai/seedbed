# Public Seedbed Repository Agent Guide

This public repository is Seedbed's customer-facing publication, support, release, and integration-contract surface. It is not the authority for private Product planning, private Engineering implementation, Company policy, Legal analysis, or other non-public internal records.

Agents operating here are constrained by canonical Seedbed governance in the private owning repositories, but must not copy private governance text or private reasoning into this public repository merely for convenience.

## Working rules

1. Read the public README, SUPPORT.md, TRIAGE.md, SECURITY.md, and relevant issue/release documentation.
2. Publish only information intentionally approved for the public boundary.
3. Do not infer supported capability from private implementation, private branches, or architecture intent. Public support/readiness must match the exact approved public artifact/contract.
4. Translate private project/customer forcing cases into the minimum generalized public requirement needed for action.
5. Never disclose private repository details, credentials, confidential source, unpublished results, private roadmap material, or internal governance provenance.
6. Route Product decisions to `seedbed-ai/product`, technical implementation/architecture to `seedbed-ai/sb`, and Company/Legal matters to their owning private authorities.
7. If a public answer depends on unavailable private authority, fail closed on the commitment rather than guessing.

Local public-process rules specialize the organization-wide governance; they do not replace it.
