# Seedbed

Seedbed is in **very early development**. Public releases and support processes are being established now, before the platform is considered stable or production-ready.

Expect defects, incomplete capabilities, breaking changes, missing documentation, and architecture that may still change materially. If Seedbed's current design blocks a serious integration, please tell us. Substantial design-change requests are welcome at this stage and are especially valuable when they come with a concrete workload or operational scenario.

## Support

For now, the supported public channel for questions, integration blockers, design requests, and bug reports is this repository's **Issues** tab.

Use the available issue templates where possible:

- integration/support question;
- bug report;
- design or architecture request.

Please avoid posting secrets, credentials, private source code, private repository URLs, customer-sensitive identifiers, or other confidential information. Describe private workloads generically when needed.

GitHub Discussions may also be enabled for community conversation, but the automated Seedbed support workflow currently operates through Issues.

## Releases

Public release artifacts and public-facing release documentation will be published here when Seedbed is ready to make them available.

Until a release is explicitly published here, do not treat internal development artifacts, branches, commits, or private repositories as supported customer releases.

## Maturity

Seedbed currently provides only a narrow subset of its intended architecture. Some areas are implemented, some are architected but not yet implemented, and others remain open design territory. Support answers should identify which category applies rather than implying a capability exists when it does not.
